# LcAgro-Procesos-Front

Frontend de la **plataforma de procesos de La Clementina** — una SPA **React** (Vite + TypeScript + Tailwind + shadcn/ui) que consume la **API .NET** del repo hermano [`LcAgro-Procesos`](../LcAgro-Procesos).

Implementa, como producto real, la idea ya validada en el **mockup navegable** de ese repo (`apps/mockup-web`): login, dashboard, **Posición de Cereal**, **Cuentas Corrientes USD**, usuarios, configuración y asistente IA.

## Documentación

La especificación completa del frontend está en [`docs/`](docs/README.md). Para programar, arrancá por [`docs/06-setup-y-entornos.md`](docs/06-setup-y-entornos.md) (cómo crear el proyecto) y seguí el [`docs/07-plan-de-implementacion.md`](docs/07-plan-de-implementacion.md).
